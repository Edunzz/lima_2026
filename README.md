# Welcome!
## Session: *Practical AI for Observability: Dynatrace MCP in Action*

In today's session, we are exploring how instruction files aid in teaching and guiding our AI assistants. Just as we can give someone tools like a hammer and nails, we must teach them how to use these tools to build a house!
Instruction files are an art and require tweaking depending on your use-cases. 

In the context of Dynatrace, we'll be focusing on using [Dynatrace's MCP server](https://github.com/dynatrace-oss/dynatrace-mcp) which provides several tools to AI assistants. More specifically, we'll be improving the `execute_dql` tool.
